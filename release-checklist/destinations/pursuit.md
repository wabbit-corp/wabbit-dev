# Pursuit Checklist

Use this together with the general checklist and [`languages/purescript.md`](../languages/purescript.md).

## Documentation Readiness

- [ ] Generated docs for public modules are useful enough to publish.
- [ ] Exported types and values that matter to users have documentation.
- [ ] Examples compile and reflect real usage.

## Package And Ecosystem Fit

- [ ] The package can be consumed through the expected PureScript package workflow.
- [ ] Dependencies are available and versioned the way we expect in the ecosystem.
- [ ] Repo and tag information used for documentation or registry integration are correct.

## Release Validation

- [ ] Generated docs correspond to the exact version being released.
- [ ] A fresh consumer project can add the package and compile against it.
